## What you get

- One icon per page in the sidebar footer. Click it and bb opens that Settings page.
- Providers and Projects by default. You can add any built-in Settings section, any enabled plugin's settings page or any project's settings.
- A settings page to choose and reorder the icons, with a filter over all pages.

## Good to know

- bb shows only a few plugin icons in the footer. The rest go into its More footer actions menu, in your order.
- Choices are stored per client, so the desktop app and a remote browser keep separate lists.
- After a change, the window reloads once, because bb registers footer items when the app loads.
- The plugin opens Settings URLs directly, since the plugin SDK has no route API. A bb update that changes Settings routes may need a plugin update.
